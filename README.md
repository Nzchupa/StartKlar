## 🚀 Erste Schritte

1. Repository klonen:

   ```bash
   git clone https://github.com/Nzchupa/StartKlar.git
   cd StartKlar
   ```

2. In Eclipse öffnen: **File → Import… → Git → Projects from Git (with smart import) → Existing local repository** → Ordner `StartKlar` wählen → **Finish**.

Ausführliche Erklärung mit Screenshots: siehe [GitHub-Anleitung](https://claude.ai/artifact/LPniiyiY4whxTCzzzv8Qn6).

## 🔁 Arbeitsweise

1. Vor dem Arbeiten: `git checkout main` und `git pull`
2. Eigenen Branch pro Issue anlegen: `git checkout -b 1-anforderungen`
3. Änderungen committen: `git add .` und `git commit -m "Kurze Beschreibung"`
4. Hochladen: `git push -u origin 1-anforderungen`
5. Auf GitHub einen **Pull Request** öffnen, `Closes #1` in die Beschreibung schreiben, Reviewer eintragen
6. Nach dem Review in `main` mergen

**Regel:** Nie direkt auf `main` committen.
